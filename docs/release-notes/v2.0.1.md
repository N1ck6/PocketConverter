## Changes

- **Digitally signed.** `PocketConverterSetup-2.0.1.exe` and `converter.exe` are now code-signed (publisher: *SignPath Foundation*), so Windows and antivirus software can verify they come from this project unmodified. See the [Code signing policy](https://github.com/N1ck6/PocketConverter#code-signing-policy).
- **Updated libraries** with the latest fixes, including security fixes for opening images and PDFs: Pillow 12.3, PyMuPDF 1.28, pillow-heif 1.8, python-docx 1.2, pdf2docx 0.5.13 and others.

## 📦 Setup

1. Download **`PocketConverterSetup-2.0.1.exe`** below.
2. Run it. Windows may still show *"Windows protected your PC"* for a while after a new release, until the file has built up download reputation. Click **More info**: the publisher should read *SignPath Foundation*. Then click **Run anyway**.
3. Pick **all users** (admin) or **just me** (no admin), and keep *Add "Convert to"…* ticked.
4. Right-click any supported file → **Convert to**.

**Upgrading from 1.x or 2.0.0:** just run the installer. It replaces the old version in place. No need to uninstall first.
**Uninstall:** Settings → Apps → PocketConverter.

Checksum: compare `PocketConverterSetup-2.0.1.exe.sha256` with the output of `Get-FileHash PocketConverterSetup-2.0.1.exe`.

Requires Windows 10 or 11 (64-bit). [Code signing policy](https://github.com/N1ck6/PocketConverter#code-signing-policy)
