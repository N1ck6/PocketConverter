## Changes

- **Fewer false antivirus alarms.** `converter.exe` is now built with its own copy of the PyInstaller loader instead of the stock one, which some antivirus engines flag because malware is packed with the same tool.
- **Updated libraries** with the latest bug and security fixes for reading images, PDFs and documents: Pillow 12.3, PyMuPDF 1.28, pillow-heif 1.8, python-docx 1.2, pdf2docx 0.5.13 and others.

No changes to how the app works. If 2.0.0 runs fine for you, updating is optional.

## 📦 Setup

1. Download **`PocketConverterSetup-2.0.1.exe`** below.
2. Run it. If SmartScreen shows *"Windows protected your PC"*, click **More info → Run anyway** (the installer isn't code-signed).
3. Pick **all users** (admin) or **just me** (no admin), and keep *Add "Convert to"…* ticked.
4. Right-click any supported file → **Convert to**.

**Upgrading from 1.x or 2.0.0:** just run the installer. It replaces the old version in place. No need to uninstall first.
**Uninstall:** Settings → Apps → PocketConverter.

Checksum: compare `PocketConverterSetup-2.0.1.exe.sha256` with the output of `Get-FileHash PocketConverterSetup-2.0.1.exe`.

Requires Windows 10 or 11 (64-bit).
