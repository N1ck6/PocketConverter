A big reliability release: over 25 bugs fixed (a few of them could lose data), new formats, multi-file conversion, and a rebuilt installer.

## ✨ New

- **Convert many files at once.** Select several files → *Convert to* → format. You get one notification such as "Converted 12 files to PNG". In 1.x the menu disappeared as soon as two files were selected.
- **Click the notification** to open the folder with the result. Notifications now show as *PocketConverter* instead of "Python"/"PowerShell".
- **More formats**
  - Video: **MOV** (iPhone), **MKV, AVI, WEBM** → MP4 / GIF / MP3 / WAV
  - MP4 → **AAC, OGG**
  - **M4A** audio
  - **.yml**, **.htm**
  - SVG → ICO
- **No FFmpeg install needed.** Audio and video conversion works out of the box.
- **Install for just me**: the installer can now install without admin rights.
- **Bilingual installer** (English / Русский), plus a Start-menu entry that explains how to use the app.
- Opening `converter.exe` directly shows a short how-to instead of crashing.

## 🐞 Fixed. Please read if you used 1.x

- **Files with a dot in their name could overwrite another file.** Converting `report.v2.txt` to PDF wrote `report.pdf`, replacing any existing `report.pdf`.
- **Text files not saved in UTF-8** (e.g. Windows-1251/ANSI) were converted into a document containing *the file's path* instead of its text.
- **TXT → PDF/DOCX/MD/HTML silently changed your text.** GPT cleanup ran on every conversion, which removed `_` and `*`, turned `π` into `pi`, and so on. Only **Clean GPT text** does that now.
- **Clean GPT text** no longer breaks `my_var_name` or `2*3*4`. It now converts `x²`, `⁴√x`, `\cdot`, `≤` and removes code fences as promised.
- **SVG conversion** failed on every PC because of a missing Cairo library. It works now and keeps the aspect ratio.
- **PNG → ICO** produced only a 16×16 icon, and non-square images were squashed. You now get 16–256 px, padded to a square.
- **Transparent PNG → JPG** gets a white background instead of black or garbage.
- **Phone photos** are no longer rotated sideways, and HEIC colours are preserved (colour profile kept).
- **Folder → PDF** ignored `.JPG` files (upper-case, as cameras save them) and sorted `img10` before `img2`.
- **GIF → PNG frames** dumped every frame into your folder. They now go into a `name_frames` subfolder.
- **GIF → MP4** videos wouldn't play in the Windows player. **MP4 → GIF** is now much smaller and better looking. A video with no sound gives a clear message instead of a crash.
- **JSON/CSV/XML/YAML**:
  - files with a UTF-8 BOM and Excel's `;`-separated CSVs now work
  - nested JSON is kept in CSV cells instead of being dropped
  - JSON → XML always produces valid XML
  - YAML dates convert
- **Error log** is written to `%LOCALAPPDATA%\PocketConverter\` (1.x tried Program Files, which normal users can't write to, so nothing was ever logged).
- No more console windows flashing during audio conversion.

## ⚠️ Changes to know about

- **Folder → PDF/GIF** output is now named after the folder (`Holiday.pdf`) instead of `Combined_images.pdf`. PDF pages are A4, portrait or landscape to fit each image.
- **Video → GIF** is capped at 720 px wide and 10 fps to keep GIFs shareable.
- Outputs are never overwritten. If `photo.png` exists you get `photo(1).png`.
- On **Windows 11** the menu is under **Show more options** (Shift+F10), as before.

## 📦 Setup

1. Download **`PocketConverterSetup-2.0.0.exe`** below.
2. Run it. If SmartScreen shows *"Windows protected your PC"*, click **More info → Run anyway** (the installer isn't code-signed yet).
3. Pick **all users** (admin) or **just me** (no admin), and keep *Add "Convert to"…* ticked.
4. Right-click any supported file → **Convert to**.

**Upgrading from 1.x:** just run the installer. It replaces the old version in place and cleans up its menu entries. No need to uninstall first.
**Uninstall:** Settings → Apps → PocketConverter.

Checksum: compare `PocketConverterSetup-2.0.0.exe.sha256` with the output of `Get-FileHash PocketConverterSetup-2.0.0.exe`.

Requires Windows 10 or 11 (64-bit).
