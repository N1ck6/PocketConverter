## Changes

- **Convert many files at once.** Select several files → *Convert to* → format. You get one notification such as "Converted 12 files to PNG". In 1.x the menu disappeared as soon as two files were selected.
- **Click the notification** to open the folder with the result. Notifications now show as *PocketConverter* instead of "Python"/"PowerShell".
- **More formats**
  - Video: **MOV** (iPhone), **MKV, AVI, WEBM** → MP4 / GIF / MP3 / WAV
  - MP4 → **AAC, OGG**
  - **M4A** audio
  - **.yml**, **.htm**
  - SVG → ICO
- **No FFmpeg install needed.** Audio and video conversion works out of the box.
- **Install for just me**: the installer can now install without admin rights.
- **Folder → PDF/GIF** output is now named after the folder (`Holiday.pdf`) instead of `Combined_images.pdf`. PDF pages are A4, portrait or landscape to fit each image.
- **Video → GIF** is capped at 720 px wide and 10 fps to keep GIFs shareable.

## 📦 Setup

1. Download **`PocketConverterSetup-2.0.0.exe`** below.
2. Run it. If SmartScreen shows *"Windows protected your PC"*, click **More info → Run anyway** (the installer isn't code-signed yet).
3. Pick **all users** (admin) or **just me** (no admin), and keep *Add "Convert to"…* ticked.
4. Right-click any supported file → **Convert to**.

**Upgrading from 1.x:** just run the installer. It replaces the old version in place and cleans up its menu entries. No need to uninstall first.
**Uninstall:** Settings → Apps → PocketConverter.

Checksum: compare `PocketConverterSetup-2.0.0.exe.sha256` with the output of `Get-FileHash PocketConverterSetup-2.0.0.exe`.

Requires Windows 10 or 11 (64-bit).
